# awesome-sleep-tracking
Curated list of tools, devices, datasets and open-source software for tracking and analyzing sleep: pulse oximetry, PAP therapy, wearables, EEG, and the metrics behind them.

## Open Source Software

- [OSCAR](https://www.sleepfiles.com/OSCAR/) - Cross-platform analysis software for CPAP, BiPAP and oximetry data from most major manufacturers.
- [o2ring-analyzer](https://github.com/nighttimecf/o2ring-analyzer) - CLI for Wellue O2Ring overnight exports: SpO2 statistics, ODI, desaturation events.
- [MNE-Python](https://mne.tools/) - Library for processing EEG and MEG data, including sleep staging workflows.
- [pyEDFlib](https://github.com/holgern/pyedflib) - Reading and writing EDF/EDF+ files, the standard format for polysomnography.

## Metrics and Definitions
- [Oxygen Desaturation Index](https://www.nighttimecomfort.com/oxygen-desaturation/) - How ODI is calculated and why 3% and 4% thresholds give different numbers.
- [AASM Scoring Manual](https://aasm.org/clinical-resources/scoring-manual/) - Official definitions used in clinical sleep scoring.
